# Rodar no computador

## 1. Instale o Node.js

Use Node 22 LTS ou versão compatível.

## 2. Abra o terminal na pasta do projeto

```bash
cd clinica-sorriso
```

## 3. Instale as dependências

```bash
npm install
```

Você faz isso normalmente apenas na primeira vez ou quando as dependências mudarem.

## 4. Ligue o site

```bash
npm run dev
```

O terminal mostrará um endereço parecido com:

```text
http://localhost:5173
```

Abra esse endereço no navegador.

## 5. Pare o servidor

No terminal, pressione:

```text
Ctrl + C
```
