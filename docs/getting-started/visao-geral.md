# Visão geral

O site usa React + Vite + TypeScript e gera arquivos estáticos na pasta `dist/`.

Isso significa que, em produção, o servidor não precisa manter Node.js rodando. O Nginx apenas entrega HTML, CSS e JavaScript.

## Páginas

- `/`
- `/clinica`
- `/tratamentos`
- `/tratamentos/:slug`
- `/equipe`
- `/contato`

## Conteúdo demonstrativo

Até o briefing ser aprovado, contatos, CROs, textos e imagens são placeholders. Não publique esses dados como definitivos.
