# Arquitetura

## Regra

- `components`: aparência reutilizável.
- `content`: dados exibidos.
- `config`: dados globais e URLs.
- `pages`: composição das páginas.
- `styles`: regras visuais.

Evite inserir telefone, endereço ou cor diretamente em vários componentes.

## Pastas principais

```text
src/
├── app/
├── components/
├── config/
├── content/
├── layouts/
├── pages/
├── styles/
├── tests/
└── types/
```
